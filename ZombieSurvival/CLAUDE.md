# ZombieSurvival

Co-op zombie survival (7 Days to Die–like) in Unity 6 LTS + URP + Netcode for GameObjects, low-poly POLYGON-style art.
The user speaks Russian — answer and write player-facing text in Russian.

- Gameplay scripts: `Assets/ZombieSurvival/Scripts/` — read `README.md` for the system map.
- The playable scene and all prefabs are generated by `Assets/ZombieSurvival/Scripts/Editor/PrototypeBuilder.cs`; extend it rather than asking the user to wire things by hand.
- Skills: `unity-gamedev` (code conventions, how to compile-check without Unity), `unity-netcode-coop` (authority model, RPC rules), `lowpoly-assets` (where to get free models and how to import them).
